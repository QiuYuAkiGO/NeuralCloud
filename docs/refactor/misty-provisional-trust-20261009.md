# Misty 暂时采纳观点与自然信任表达

本次修复把置信度的用途限定为认识的成熟程度和结论强度。普通自述、作品设定、合理临时解释可以直接成为当前对话前提；当下信任、好感、靠近意愿、保留意见和拒绝不需要先证明长期关系。原有温柔、慢热的人设、初始置信度、稳定阈值、跨天要求、情绪参数和独立证据计数均不调整。

## 实现与事实边界

- `harness/core/conversation_policy.py` 提供共享静态规则，接入群聊/私聊规划、正文生成和 JSON 语义审查。普通来源说明不再自动生成 `necessary_boundary`；实质矛盾、重要后果或明确核实任务仍需要限定。
- 当前态度、可修正假设、条件性建议使用原有 `non_factual / not_asserted / none`。忠实承接自述仍关联原作者的 `user_claim`；没有声称独立核实时，不要求例行加入免责声明。
- 同一句里的态度与事实前提分别审查。“我相信你”不要求历史证明，“因为你从没骗过我，所以我相信你”的历史仍需证据。自身经历、共同历史、身份权限、执行结果和已经成立的关系不能通过“我猜”免检。
- 会话来源与可见范围分别核对：允许在当前群召回的记录，不等于原话发生在当前群。跨人归属保护、图片/OCR 的模型推断属性以及证据裁剪边界保留。
- 修订只针对具体越界，保留合法观点、亲近意愿和当前交流任务；没有增加审查阶段或修改报告/回复计划/发送协议字段。

## 稳定印象兼容

`MemoryEvidenceEntry.status` 新增 `stable_interpretation`，与 `retained_fact` 分开。QQ 群聊、私聊、日常认识召回及本地共享记忆使用同一映射：明确争议优先；明确稳定状态映射为稳定主观认识；其余保持暂定。单个高置信度和 evidence-v2 的 `support_only` 不推导稳定。

历史反例仍完整保留。已有写入机制允许印象在后续独立支持后重新稳定，因此明确恢复的 `stable` 不因仍保留历史反例而再次降级；反例作为独立 `disputed` 证据提供给生成和审查。若原状态或元数据明确标记争议，争议优先于稳定。稳定认识仍不能支持“你一直如此”“从未有例外”。已发送的信任表达仍属于自身表达，不能增加对方可靠性的独立证据。

兼容基线提交 `90807d1` 能读取新增状态，但保留保守判断。它同时保留服务器已经运行的当前消息证据纳入、当前消息不冒充历史、原作者保护和限时报告修复逻辑。没有改写历史内容、重新计分或迁移记忆系统。行为实现提交为 `1f372ff`。

## 评估方法

工程测试覆盖状态映射、争议优先、检查点/证据 JSON 往返、原始来源不变、证据裁剪、图片推断、跨会话/私聊边界、既有信心计算和自主证据计数。回退基线另外执行读取和证据投影测试。

真实评估使用 `tools/production_acceptance/conversation_acceptance_cases.json` 的 90 个去重场景：既有 55 例、本轮 20 例和补充的 15 个边界例，每例运行三次。初始集合为 88 例，逐项审阅完整回放后增加一对否定历史/正确保留反例的实际场景，没有删除旧样本。使用冻结的真实 Persona 和原餐馆事件证据，其余为合成输入；原始私人上下文和凭据只留在服务器私有评估目录。

完整回放使用隔离 SQLite 状态、同一冻结情绪指导和来源记录，覆盖群聊/私聊各四类场景：作品背景、临时解释、当前关系态度、出现反证。每种输入在基线和候选版本各预热一次，再交错测量三次，共 48 个正式回放；预热的 16 次单独保留。所有失败计入结果，不通过重试、删样本或替换候选文本提高通过率。回放不发送 QQ 消息、不写线上记忆。

HTTP 观测记录实际模型、用量、缓存命中、调用数和耗时。P95 使用最近秩法；允许增量为基线 P95 的 10% 与 0.5 秒中的较大值。语义结论由实际 JSON 校验器产生；另逐项审阅候选正文与规划，检查多余免责声明、强制亲近和反证处理。

## 评估过程中修复的问题

第一轮 264 次中有 6 次未达标：跨群原话被错误搬到当前群三次；正确保留反例的回复因非事实分句漏填 `evidence_rows` 三次。补充会话来源比较、必填空列表要求后，全套 264 次通过。

随后完整回放发现一次 JSON 引号缺失。传输层的严格结构校验早于已有报告修复循环抛错，导致合法的“慢慢了解”回复未放行。本次把限定的报告格式错误接入原有最多两次、共用 8 秒的尝试预算，仍然拒绝超时、拒答、连接失败或两次无效报告，不增加正常审查阶段。只有报告已修复并通过且没有更早故障时，才清除该次格式错误在 QQ 调用器留下的失败标记。

模型还可能反复省略非事实分句的空引用列表。解析时将缺省 `evidence_rows` 规范化为 `[]`，不增加报告字段或补造引用。`supported + evidence` 仍必须包含非空、有效的已准入证据行；缺省列表绝不能支撑事实。格式错误和语义不完整仍失败关闭。所有初始失败及中间结果保留用于审计。

逐项审阅完整回放时，还发现一个自动审查漏检：“我不知道哦，你又没跟我说过。”前半句是当前认知状态，后半句却是缺乏完整历史支持的否定事实。已将这种混合表达加入共享规则和语义逐句检查，并把实际失败句及合规对照补入固定回归集。该轮技术结果虽为 24/24 ready，人工语义验收仍判定未达标，没有发布。

最终验收数值、完整合成回放和部署验证保存在 `docs/harness/evidence/misty-provisional-trust-20261009/`。这些门槛仅用于本次发布验收，不代表所有自然对话的准确率。
