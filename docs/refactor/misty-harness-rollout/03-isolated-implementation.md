- 归档管理面：有界加密批次、哈希/引用检查、外部恢复签名回执、两个经过管理方核实的独立物理故障域、revision 屏障和在线脱离。真实本地清除仍被代码禁止；没有宣称已完成冷数据离机。
- 授权恢复：签名绑定角色、数据库实例、批次/密文哈希、具体记录、目标环境、用途与期限；只永久重新纳入获批的记录，幂等执行，先核对当前撤销、修订和来源版本。无当前占位与更正账本时拒绝恢复；暂时查阅及到期清理编排仍待后续管理流程。
- 旧生产记忆迁移：不导入旧推理/GUI/身体运行时；固定快照哈希，分批事务、持久游标和未完成启动门禁；保留原 ID、时间、来源/私密元数据、重要性、支持/反驳关系、supersession 与原版本哈希。旧解释标明历史模型认识，旧执行任务不重放。

## 数据验证

实际生产记忆库经 SQLite backup API 得到一个 1,274,318,848 字节的单库一致快照，在 I: 维护区加密保存，解密后校验原库 SHA-256、SQLite 完整性及计数。I: 中的恢复副本仅用于隔离验证；没有修改原生产数据库。验证完成后删除了本轮在 Linux `/tmp` 创建的额外快照，保留加密维护副本及验证材料。

转换结果：39,811 条记录、39,816 个版本；34,875 条 ONLINE、4,840 条 INACTIVE、96 条 SOURCE_CHANGED。逐版本核对全部 39,816 份文本及原 payload 哈希，并检查来源外键与全文索引 rowid 对应关系。失效/来源不可用记录仍在维护数据中，未把它们恢复为当前可用事实。

最终一次完整转换步骤耗时约 38.3 秒，不含最初快照传输、哈希检查和临时索引构造。中途断进程后的事务恢复也实际执行过。真实数据发现的旧别名查找和 FTS 删除重复扫描已修复：使用维护连接的磁盘临时索引及主表 rowid 定位，未修改冻结的原始库。

这个快照只证明记忆数据库的一致性，不是跨 NeuralCloud、MistyAI、QQ、Harness 和附件的完整恢复点。原 SQLite 还保留退役执行/情绪账本，转换结果是在线投影，不能据此删除原始快照。

## 测试和测量

Windows Python 3.12.13 / Node 24.15.0 与 Linux Python 3.12.3 / 隔离 Node 24.15.0 均通过 **41 项测试**：NeuralCloud 15、MistyAI 10、NC 插件 3、Harness/QQ 12、跨服务联调 1。Ruff、契约漂移检查和两个 wheel 构建通过，wheel 逐项确认没有旧身体/语音/GUI 运行模块。

跨服务测试确实启动两个 HTTP 服务和 npm Harness/JSONL，使用 synthetic 模型、QQ SDK sender 与字幕提供者。验证跨会话记忆、入站去重、WAIT、显式发送、一次性审批、实际内容回执、自评和纠正失效。它不等于真实 QQ 接收方或真实视频验收，未发生外部测试发言或模型调用。

新进程测量边界为“导入 memory domain → 打开 SQLite → health 可用”，不含解释器启动、HTTP/网络服务和语义索引。操作系统缓存未清空，不能称为物理冷启动。Windows 代表性结果如下：

| 数据量 | 重复次数 | 就绪中位数 | 就绪 RSS 中位数 |
|---|---:|---:|---:|
| 合成 0 条 | 3 | 87.4 ms | 34.20 MiB |
| 合成 1,000 条 | 3 | 86.3 ms | 34.27 MiB |
| 合成 10,000 条 | 3 | 92.4 ms | 34.21 MiB |
| 实际投影 39,811 条 | 5 | 92.0 ms | 34.24 MiB |

不同数据的命中分布不同，不能直接用查询耗时比值推断生产加速倍数。旧服务日志的 systemd 激活窗口与 cgroup 内存也不等于新服务的 domain 计时/RSS，尚未完成严格同条件旧新分段对照。没有设立或宣称满足某个启动秒数门槛。
