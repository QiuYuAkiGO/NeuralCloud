## 1. 已实现的修复

| 顺序 | 原问题 | 本次处理 |

| 1 | 自评引用被 128 条截断挤出已知证据集合，请求在模型调用前失败 | 统一选择证据，优先保留当前快照、目标绑定、已执行步骤的证明与自评依据；保留旧步骤对应的结果证明；提交 Cognitive 前验证完整请求。完整历史仍留在账本。 |

| 3 | 重规划关注 novelty，实际仍按旧 social_connection 基线评价 | 重规划保存原评价窗口，再同步更新目标维度、当前基线和评价起点；贡献按新窗口筛选。 |
| 3 | 每次“低于最初基线”都被误读为又恶化一次 | 同时保留相对计划起点的结果和相对上次观察的变化；界面明确两种比较。继续保留 `causal_effect_verified=false`，不把相关变化宣称为行动的因果效果。 |
| 3 | 工具回执缺少信息收益反馈 | Web 结果增加新出现或内容变化的来源数、重复来源数、空结果及有界内容摘要；后续评价允许正向、零和负向判断。工具成功不直接奖励心理数值。 |
| 3 | OneBot 近期消息未接入旧目标调节的事实链路 | Runtime 定期读取已绑定的协议观察，验证活动运行、群范围、冻结观察和原始协议哈希；仅提交近期非自身、非历史消息的事实，使用持久身份去重。普通消息不等于已被理解或已获得积极回应。 |
| 3 | 模型返回期间的心跳导致心理评价版本冲突 | Runtime 显式允许短时重基；Homeostasis 必须证明旧版本至当前版本之间是连续的纯心跳，且快照不超过 60 秒。发生真实事件、缺少轨迹、超过期限或无明确授权时仍拒绝。保留原依据版本和实际应用版本；重放不重复产生收益。 |
| 4 | 尝试、有效决策与真实动作混淆 | 目标接口增加最近一小时的尝试、有效决策、等待/错误状态、已执行能力统计，以及 QQ 事实采集状态。保持既有频率预算，先观察修复后的行为。 |

## 2. 频率与证据约束

保留 5 秒心跳、60 秒输入安静期、每小时最多 12 次目标评估尝试、至少 60 秒重评间隔、300 秒常规复查、1,800 秒表达冷却，以及自主 Web 每日最多 20 次的现有配置。前置请求校验失败不再占用模型调用预算；故障锁仍阻止同一错误在每个心跳重复尝试。

新增的活动时长与尝试数是调度约束，不要求 Misty 每次低新鲜感都搜索。收到真实消息继续遵守输入优先与安静期；事实采集本身不调用模型、不发送消息。协议采集目前覆盖配置中允许观察的群消息，未扩展私聊事实模型。

普通近期消息只触发既有低权重事实作用，不固定增加社会连接；积极回应、理解或心理改善需要额外证据和评价。Web “新来源”按当前目标上下文中 URL 与内容摘要对比，不代表全球首次出现，也不自动代表来源真实可信。

## 3. 验证结果

- Linux 广覆盖回归：**1,064 passed，9 skipped**，耗时 142.23 秒；跳过的是需要显式启用环境的测试。涵盖目标、QQ 协议与来源、能力边界、内稳态、心理评价等 56 个测试文件。
- 最终生命周期调整和最终源码复验：**109 passed**，耗时 6.35 秒。此集合与上面的集合重叠，不应相加作为独立测试数。
- Windows 针对性回归：158 passed；Ruff 与 Git 空白检查通过。
- 历史请求重放：从线上只读账本取 2026-10-05 起的 **37** 份目标请求，原构造 **0/37** 有效；用新的证据选择逻辑重建后 **37/37** 有效。原调研的 33 份是较早取证时的样本，差异来自本轮继续取样。
- 真实模型隔离对照：当前模型及人格预设，目标带内/低 novelty 各两次，共 **4/4** 有效决策；单次 5.334–10.740 秒，全部选择等待，其中一次低 novelty 决策显式关注 novelty。没有 Runtime 事件写入、QQ 发送或 Web 执行。

模型对照使用空的共享记忆/近期对话，只提供搜索能力，关闭隔离样本的情绪渲染；它验证请求到模型结果的契约与时限，不等同于完整线上人格、记忆和环境复现。样本很小且全部等待，不能据此声称已经证明“低新鲜感会提高搜索率”，也不能把等待判断为失败。

回归特别覆盖：超过 128 条证据、旧步骤证明保留、故障跨重启保持、等待不累计失败、活动超时、暂停/未知效果/执行中保护、重规划评价窗口、重复/空 Web 结果、协议篡改/历史/自身消息，以及心理评价只跨纯心跳重基。
