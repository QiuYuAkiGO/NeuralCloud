# Misty 口语表达对照试验：结果与待评事项

日期：2026-10-28。状态：自动回放及材料交付完成；人工盲评待完成；未部署生产变更。

## 当前结论

保留现行 A 组生产策略。B–E 已显示缩短表达的趋势，但尚无人工自然度、具体性与人设评分，不能宣布胜出或达到 60% 偏好门槛。

若按改动成本安排人工复核，先看 B：只增加短表达规则，首条候选消息的中位长度从 A 的 70 字降为 49 字。C、D、E 分别为 46、47、42 字。示例和末尾提醒仍可能有价值，但本批长度变化不能证明自然度改善，也不能证明 D 的去重有效。

## 运行与口径

- 24 个真实历史片段＋12 个合成案例，五组各三次，共 540 个正式轮次；每组 108 轮。
- 使用生产安装的 Session 投影、AgentLoop 和 PiAi 适配器，固定 deepseek-flash、4096 输出额度和现有工具 schema。当前捕获的系统提示与模型参数应用于历史上下文；全部真实片段标为重构，不宣称历史 HTTP 请求逐字重现。
- 最终 532 轮执行完成、8 轮不可评、无剩余模型错误。完成表示回放结束，不表示回答正确或真实送达。
- A/B/C/D/E 的已发候选轮数分别为 80/79/75/79/79，首条消息中位长度为 70/49/46/47/42 字。各组参与集合不同，这些是描述性统计，不是控制参与差异后的因果效应。
- 含问号的候选轮数分别为 12/6/6/8/5。问号只是机械指标，不能等同于无意义追问。
- 全部发送与写入均由隔离模拟处理器承接；没有连接真实 QQ 或生产记忆写入服务。运行结束时生产服务仍 active，MainPID 保持 1754067。

## 必须保留的失败与限制

第一次六例检查发现请求拦截未生效，全部作废。修复后六例通过，并逐项核验实际请求消息、工具 schema 和模型参数。

首批正式结果有 225 轮 `UNSUPPORTED_CONTENT`，原因是隔离实例缺少持久附件服务。按内容哈希复制并校验 35 个图片对象，六个含图契约检查通过后，统一重跑全部受影响轮次。原始 225 条失败结果保留在 attempts 目录；没有挑选同条件下较好的一次。正式尝试共 765 次，对照表只使用修复后的 540 个轮次。

8 轮不可评来自缺少冻结读取证据：天气查询调用内容读取 5 次，重复话题案例调用记忆检索 2 次，偏好问题调用记忆检索 1 次。没有用事后检索填补历史证据，也没有虚构工具成功。

另需人工检查：49 轮没有调用发送或等待工具，不能直接解释为明确选择等待；12 轮出现相同文本的重复发送尝试。重复尝试分布为 A/B/C/D/E 的 3/2/1/3/3。模拟回执有明确 simulation 标识，与真实送达回执不同，可能影响后续行为；这些结果不能直接当作生产重复发送率，也不能隐藏。盲评材料保留每次发送尝试。

尚未验证“更短”的回复是否遗漏明确请求、扭曲内容或丢失 Misty 的声音。不得用长度指标替代这些检查。
