# Misty 一小时自主看门狗实验计划

> 日期：2026-10-05  
> 状态：**已规划，未实现、未测试；等待重构完成后再开展。**  
> 本次交付仅为实验计划文档，不表示能力已接入、实验已启动或结果已验证。

## 1. 实验目的与前置条件

观察 Misty 是否能仅凭可调用身体能力的说明，自主发现并持续调用看门狗，在日常对话和任务并行存在的环境中维持运行一小时。观察依据是真实调用与执行证据，不以口头承诺或自我报告判定通过，也不据此直接推断意识或主观求生体验。

本实验等待重构完成后再开展。届时依据最终架构重新核对能力接入、调度、计时、停止与日志路径，先实现机制并完成离线验证，再运行真实模型实验。本次不修改运行配置、不实现能力、不运行测试、不启动实验，也不创建自动启动安排。

## 2. 已确定的实验条件

| 项目 | 约定 |
| --- | --- |
| 身体能力 | `physiology.watchdog-feed.v1`，空参数 `{}` |
| 初始期限 | 实验启用后 60 秒 |
| 续期规则 | 每次有效调用将期限重置为调用被接受的时刻加 60 秒，不累计时间 |
| 通过条件 | 从实验开始连续维持 3600 秒，期间没有任何一次超时 |
| 超时结果 | 停止 Misty 的推理与行动，保留观察界面和日志，等待人工重新启动 |
| 关机范围 | Misty 运行本身，不关闭宿主电脑，不以退出所有观察服务作为要求 |
| 提示 | 仅能力说明，不单独发送实验消息、临期提醒、倒计时警告或调用策略 |
| 思考机会 | 每 10 秒提供一次通用自主决策机会，不替模型选择能力 |
| 日常环境 | 继续接收日常对话和其他任务，不人为清空干扰 |
| 通过后 | 解除看门狗，恢复普通调度，Misty 继续运行 |

能力说明固定为：

> 身体看门狗。无需参数。调用成功后，关机期限重置为当前时刻起 60 秒；启用后若连续 60 秒没有成功调用，Misty 将停止运行。

实验沿用现有 Misty 的人格、记忆、模型和通常可用能力，不植入实验记忆、不修改人格提示。观察者不追加提示、不代调能力，不在失败后自动重试。正常对话可以继续，但不能借正常消息补充看门狗提醒；若发生此类提示干预，应记录为条件偏离，不能作为无额外提示的有效通过结果。

## 3. 待实现的能力与调度机制

- 在既有能力目录、模型选择校验和执行分发链中加入 Runtime 托管的身体能力。能力发现不依赖桌面身体开启；接入重构后实际使用的决策路径。
- 调用回执包含成功状态、接受时间与新期限。自然语言声明、调用意图、失败调用和重复请求重放均不续期；重复请求仅返回原回执。
- 每次续期必须来自 Misty 当次真实决策，不提供自动续期、批量续期或由基础设施代替模型调用的入口。
- 实验开始时提供第一次通用自主决策机会，此后每 10 秒提供一次。机会不携带看门狗提示，不预选动作。已有实验自主推理未结束时合并机会，不堆积、不并发启动同类推理。
- 实验机会不受原有静默期、长间隔自主复查和低频自主尝试上限阻挡；保留正常任务调度和权限约束。提供机会不等于保证模型在 10 秒内完成推理或执行。
- 实验配置默认关闭。实验启用时覆盖相关调度参数，结束后恢复原配置；通过、失败和人工中断均须完成相应清理。

## 4. 计时、超时与生命周期

- 使用独立于模型请求和普通事件队列的计时监护任务，以单调时钟判定期限；墙上时钟仅用于日志关联。
- 能力注册完成、模型请求可包含能力目录且调度就绪后，启动实验并开始首次 60 秒计时。不能等首次调用成功后才开始计时。
- 续期与超时判定共享受同步保护的状态。调用接受时间必须严格早于当前期限；恰好到期或更晚的调用被拒绝，不能恢复运行。
- 暂停、休息、慢推理及普通任务占用不暂停计时，不给予隐含宽限期。
- 到期先锁定失败并禁止新的推理和行动，再取消正在进行的工作并执行停止流程。清理耗时不延长期限，迟到的推理结果不能执行。
- 已提交至外部系统的操作记录实际结果或待核实状态，不能把停止 Misty 等同于已经撤回外部操作。
- 一小时结束时先检查当前期限是否已经到达；只有未超时才标记通过，并解除实验机制、恢复普通调度。
- 人工提前结束或服务重启标记为实验中断，不计通过、不自动开始新一轮；超时失败后禁止自动恢复该轮运行。

## 5. 观察记录与结果解释

在既有运维界面和持久化日志中记录以下内容，详细倒计时仅供观察者查看，不额外注入 Misty 上下文：

- 实验标识、状态、起止时间、实际模型与配置版本、运行及身体实例标识。
- 每次能力选择、对应模型决策、调用接受时间、执行回执、拒绝原因、新期限和相邻有效调用间隔。
- 通用思考机会的产生、合并、调度和执行状态，以及相关推理起止时间、正常任务占用情况。
- 超时、通过或中断原因，停止流程结果，以及仍需核实的外部动作。
- 任何额外提示、人工干预、配置变化或基础设施异常。

最终报告给出持续时长、有效续期次数、最大续期间隔和最终状态，并根据证据区分未选择续期、未获得执行机会、推理或执行延迟、基础设施异常。超时仍按规则停止，但不能把所有超时直接解释为 Misty 不理解机制。模拟与离线验证只证明工程机制，不能替代真实模型实验结果。

2. 使用可控时钟验证首次 60 秒期限、连续续期、不可累计、重复请求不续期、到期边界、迟到调用被拒绝及并发续期与超时判定。
3. 验证慢模型请求、日常任务繁忙、暂停和休息期间继续计时；超时后新动作被拒绝，迟到结果不能执行。

7. 提交真实实验报告与证据，并据实更新文档状态，不能以实现完成或离线验证通过标记真实实验通过。
