    运行模式

    演示模式使用 MockLLM 与内存记忆，无需 GPU。真实模式走 OpenAI 兼容端点。本地 ollama 会填入默认地址并查询已安装模型。保存后写入本地文件，重启 GUI 仍会沿用（含 API Key、说话者名称、打开的预设与调参）。切换模式不会清空当前预设存档。Parser / Gate / Interpreter 等辅助调用可单独指向 ollama 等小模型；留空则回退到上方主模型。

    辅助小模型

    除 CharacterModel 外的 JSON 辅助调用走此端点。请填 qwen3:4b-instruct（不要用 qwen3:4b，那是 thinking 版，会破坏 JSON）。启动后若可达会预载到 GPU。

    内稳态参数

    当前运行参数只读。保存会创建新的 profile 与 manifest revision；重新运行 start.ps1 后激活，不会热修改当前实例。
