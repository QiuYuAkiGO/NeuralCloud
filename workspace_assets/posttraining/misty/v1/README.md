# Misty 后训练样本 v1

用户发言以远端共享记忆归档中的原文为准，包含原有标点、用字和大小写。通用 Chat Worker 的历史消息和目标回复取自同一会话中的已配对归档记录。两种 Master 样本共用这些消息作为材料，心声是根据材料写的训练目标。关系分档的三档条件及回复是人工标注，三档共用完全相同的一条归档用户原话。

| 文件 | 行数 | 内容 |
| --- | --- | --- |
| [master_materials_sft.jsonl](master_materials_sft.jsonl) | 20 | 10 组双轮场景。纯文本材料与心声，材料末尾保留两个换行。 |
| [master_heart_prompt_sft.jsonl](master_heart_prompt_sft.jsonl) | 20 | 相同材料与心声，在材料后另起一段加「写下此刻的心声。」 |
| [chat_worker_sft.jsonl](chat_worker_sft.jsonl) | 20 | 10 组双轮真实对话摘录，包含对应的实际送达回复。 |
| [chat_worker_relationship_sft.jsonl](chat_worker_relationship_sft.jsonl) | 30 | 10 条归档用户消息，每条分别配低、中、高三档标注。 |

## 网页编辑器

在仓库根目录用项目的 Python 3.12 环境运行 `python workspace_assets/posttraining/misty/editor.py`，然后打开 [本机编辑器](http://127.0.0.1:8768/)。网页可以切换四个 v1 样本集，按编号、关系档或正文筛选。Master 用纯文本编辑框，Chat Worker 按角色逐条编辑消息正文。

点击「保存样本」会将 Prompt 和回复写回当前 JSONL 的对应行。人工修改后如需声明用户消息仍与归档一致，请按下列索引重新核对原文。关系对照中的三档使用同一句用户消息。

### Prompt 的前文

每条 Prompt 先呈现相关的真实历史，再给出本轮用户原话。聊天样本保留历史消息的发言角色，Master 将同样的材料渲染成有发言归属的自然语言。第二轮还包含第一轮真实回复与有用的轮间消息。当前训练目标之后的消息不进入本轮材料。关系分档三行共用前文与本轮原话，熟悉程度仍由当轮关系条件给出。

## 训练与评审

- 每行包含 `id`、`group_id`、`turn`、`prompt` 和 `completion`。关系样本另外带 `relationship_tier`，三档是对照条件。线上关系分的数值和切档阈值尚未定义。
- Master 的输入和目标是字符串。关系分档和通用 Chat Worker 的输入是消息数组，目标为单条 `assistant` 消息。通用样本从归档保留历史，关系样本在 `system` 提供本轮测试所用的关系条件。两种 Master 版本分别使用自己的输入格式。 [Java 首期实施方案](../../../../docs/proposals/master-worker-router-java-implementation-20261118.md)
- 先按来源会话划分，再取训练列。相同会话的各组、同组双轮和关系三档一起分到同一侧。然后用 TRL 的 `completion_only_loss=True` 训练，核对聊天模板能渲染连续的用户消息，并核对分词后的边界与目标掩码。 [TRL SFT 文档](https://huggingface.co/docs/trl/sft_trainer)
- 评审关系分档时，比较相同输入下的表达分寸。熟悉程度可以让表达更直接或更俏皮，明确收尾仍应收住。通用档案回复反映历史会话，用事实依据和人物语气评估其作为训练目标的适用性。
- [v0 样本与反例](../v0/README.md) 是上一批合成场景的对照，保留原样。v1 使用新的样本编号，v0 的反例对应其原场景。

在仓库根目录加载任一文件，先按下例分组，再选择训练列：

```python
from pathlib import Path

from datasets import load_dataset

root = Path("workspace_assets/posttraining/misty/v1")
file_name = "chat_worker_relationship_sft.jsonl"
held_out = {"rel-07"}  # 关系文件中来自会话 C 的全部样本。

rows = load_dataset("json", data_files=str(root / file_name), split="train")
train = rows.filter(lambda row: row["group_id"] not in held_out)
evaluation = rows.filter(lambda row: row["group_id"] in held_out)
columns = ["prompt", "completion"]
train = train.select_columns(columns)
evaluation = evaluation.select_columns(columns)
```
